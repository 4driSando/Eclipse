# Repositorio de Ejercicios de Programación en Java

## Descripción General

Este repositorio es una colección completa de mis ejercicios y proyectos de programación realizados durante el curso de desarrollo de software. Está organizado por unidades temáticas, cubriendo desde conceptos básicos de programación hasta temas avanzados de orientación a objetos, estructuras de datos y manejo de excepciones. Además, incluye proyectos específicos, exámenes y prácticas adicionales que demuestran mi progreso y aprendizaje en el lenguaje Java.

El repositorio está estructurado para facilitar la navegación y el estudio, con cada unidad conteniendo ejercicios prácticos que ilustran los conceptos teóricos aprendidos. Todos los proyectos están desarrollados en Java y utilizan el IDE Eclipse para su gestión.

## Unidades de Aprendizaje

### Unidad 2: Elementos de un Programa Informático

Esta unidad se enfoca en los componentes fundamentales de cualquier programa informático. Incluye ejercicios sobre:

- Declaración y uso de variables y constantes
- Operadores aritméticos, lógicos y de comparación
- Estructuras de control básicas (if-else, bucles)
- Entrada y salida básica por consola

**Archivos principales:** `src/principal/`, `src/principal2/`, `src/principal3/`

### Unidad 3: Introducción a la Orientación a Objetos

Introducción a los conceptos básicos de la programación orientada a objetos (OOP). Los ejercicios cubren:

- Definición de clases y objetos
- Encapsulamiento básico
- Constructores simples
- Métodos de instancia

**Archivos principales:** `src/ejercicios/`

### Unidad 4: Desarrollo de Clases

Enfoque en el diseño y desarrollo de clases más complejas. Incluye:

- Constructores parametrizados
- Métodos getter y setter
- Sobrecarga de métodos
- Diseño de clases cohesivas

**Archivos principales:** `src/ejercicios/`

### Unidad 5: Estructuras de Almacenamiento

Prácticas sobre estructuras básicas para almacenar datos. Cubre:

- Arrays unidimensionales y multidimensionales
- Manipulación de arrays
- Algoritmos básicos de búsqueda y ordenamiento
- Introducción a listas simples

**Archivos principales:** `src/ejercicios/`

### Unidad 6: Colecciones

Uso avanzado de estructuras de datos proporcionadas por Java. Incluye:

- Listas (ArrayList, LinkedList)
- Conjuntos (HashSet, TreeSet)
- Mapas (HashMap, TreeMap)
- Iteradores y operaciones de colección

**Archivos principales:** `src/ejercicios/`

### Unidad 7: Excepciones

Manejo de errores y situaciones excepcionales en programas Java. Cubre:

- Try-catch blocks
- Tipos de excepciones (checked vs unchecked)
- Creación de excepciones personalizadas
- Buenas prácticas en el manejo de errores

**Archivos principales:** `src/ejercicios/`

### Unidad 8: Uso Avanzado de Clases

Conceptos avanzados de OOP y diseño de software. Incluye:

- Herencia múltiple niveles
- Polimorfismo y sobreescritura de métodos
- Interfaces y implementación
- Patrones de diseño básicos
- Clases abstractas

**Archivos principales:** `src/ejercicios/`, `src/interfaces/`, `src/ejerciciorepaso/`, `src/ejerciciorepaso2/`

### Unidad 9: Archivos y Entrada/Salida

Trabajo con archivos y operaciones de entrada/salida. Cubre:

- Lectura y escritura de archivos de texto
- Manejo de archivos binarios
- Serialización de objetos
- Uso de streams y buffers

**Archivos principales:** `src/ejemplos/`, `src/ejercicios/`, `src/ejerciciosBinarios/`
**Archivos de ejemplo:** `DOCS/` (contiene archivos de texto para pruebas)

## Proyectos Específicos

### DocCuentas

Proyecto dedicado a la gestión de cuentas bancarias o financieras. Incluye clases para representar cuentas, transacciones y operaciones básicas de banca.

**Características:**
- Documentación completa generada con Javadoc
- Ejemplos de uso de OOP en contexto financiero

### DocFiguras

Proyecto sobre figuras geométricas. Implementa clases para diferentes tipos de figuras (círculos, rectángulos, triángulos) con cálculos de área y perímetro.

**Características:**
- Herencia y polimorfismo aplicados
- Documentación técnica incluida

### PrestamosPersonas

Sistema para gestionar préstamos personales. Incluye módulos para personas, préstamos y cálculos de intereses.

**Características:**
- Uso de módulos Java (module-info.java)
- Reportes de análisis de código (CPD reports)

### PruebasAdrian

Espacio para pruebas y experimentos adicionales. Contiene utilidades y aplicaciones de prueba.

**Características:**
- Clases de utilidad reutilizables
- Tests unitarios incluidos

## Tecnologías y Herramientas

- **Lenguaje de Programación:** Java (versión 8 o superior recomendada)
- **Entorno de Desarrollo:** Eclipse IDE
- **Control de Versiones:** Git
- **Documentación:** Javadoc para generación automática de docs
- **Análisis de Código:** CPD (Copy-Paste Detector) para detección de duplicados

## Requisitos del Sistema

- Java Development Kit (JDK) 8 o superior
- Eclipse IDE instalado
- Sistema operativo: Windows, macOS o Linux
- Espacio en disco: Al menos 100 MB para todos los proyectos

## Instalación y Configuración

1. **Clonar el repositorio:**
   ```
   git clone <url-del-repositorio>
   cd Eclipse
   ```

2. **Importar proyectos en Eclipse:**
   - Abrir Eclipse
   - File > Import > General > Existing Projects into Workspace
   - Seleccionar la carpeta raíz del repositorio
   - Importar todos los proyectos disponibles

3. **Verificar configuración:**
   - Asegurarse de que el JDK esté configurado en Eclipse
   - Verificar que los proyectos compilen sin errores

## Cómo Ejecutar los Proyectos

1. **Compilar:**
   - En Eclipse: Project > Build Project
   - O desde línea de comandos: `javac -d bin src/*.java` (ajustar según la estructura)

2. **Ejecutar:**
   - Para clases con método main: Run As > Java Application
   - Para proyectos específicos, buscar la clase principal en el paquete correspondiente

3. **Generar documentación:**
   - Para proyectos con docs: Ejecutar `javadoc` en la carpeta src
   - Los archivos HTML se generan en la carpeta `doc/`

## Estructura de Archivos

Cada proyecto sigue una estructura estándar de Java:

```
Proyecto/
├── src/           # Código fuente
│   └── paquete/
├── bin/           # Archivos compilados (.class)
├── doc/           # Documentación generada (opcional)
└── README.md      # Documentación específica del proyecto (si existe)
```
