# Repositorio con mis Ejercicios de Programación

Este es mi repositorio personal que contiene todos mis ejercicios de programación realizados durante el curso. Aquí encontrarás una colección organizada de proyectos y prácticas que cubren diversos temas de desarrollo de software.

## Estructura del Repositorio

### Carpetas Principales por Unidades

- **Unidad2/**: Identificación de los elementos de un programa informático. Esta carpeta contiene ejercicios básicos sobre los componentes fundamentales de un programa, como variables, constantes, operadores y estructuras de control.

- **Unidad3/**: Introducción a la orientación a objetos. Aquí se incluyen prácticas iniciales sobre conceptos OOP como clases, objetos, encapsulamiento y herencia básica.

- **Unidad4/**: Desarrollo de clases. Ejercicios enfocados en la creación y diseño de clases, incluyendo constructores, métodos y atributos.

- **Unidad5/**: Estructuras de almacenamiento. Prácticas sobre arrays, listas y otras estructuras básicas para almacenar datos.

- **Unidad6/**: Estructuras avanzadas de datos: Colecciones. Esta unidad cubre el uso de colecciones como listas, mapas, conjuntos y sus operaciones avanzadas.

- **Unidad7/**: Excepciones. Ejercicios sobre manejo de errores y excepciones en Java, incluyendo try-catch, throws y creación de excepciones personalizadas.

- **Unidad8/**: Uso avanzado de clases. Prácticas avanzadas sobre herencia, polimorfismo, interfaces y patrones de diseño.

### Otros Proyectos y Documentos

- **DocCuentas/**: Documentación y ejercicios relacionados con cuentas bancarias o financieras.
- **DocFiguras/**: Documentos y prácticas sobre figuras geométricas.
- **Examen_WorkSpace/**: Espacio de trabajo para exámenes y evaluaciones.
- **PrestamosPersonas/**: Proyecto relacionado con préstamos personales.
- **PruebasAdrian/**: Pruebas y experimentos adicionales.

## Tecnologías Utilizadas

- Lenguaje principal: Java
- IDE: Eclipse
- Control de versiones: Git

## Cómo Usar

Cada carpeta contiene proyectos de Eclipse que pueden ser importados directamente. Asegúrate de tener Java y Eclipse instalados para ejecutar los ejercicios.
